# Project Overview
This project is a personal health tracking web app. It replaces my Airtable instance.
The app should track the fields in the .csv file in the /Data folder (and should load the existing values I pulled from AirTable) as I input them whenever I weigh myself, or get results back from lipid panels, etc.

# Tech Preferences
I want a simple web app that works on my iPhone:
- Mobile-first design
- Simple forms to enter values or to add new fields or remove fields I no longer want
- A summary dashboard with charts
- Lightweight hosting (Netlify, GitHub Pages, or local)

# UI/UX Preferences
- Dashboard should not have a header title - keep it clean
- "Most Recent Stats" title above the quick stats cards (Weight, Waist, BP)
- Charts should show year in x-axis labels (e.g., "Jan 15, '25") for clarity across year boundaries
- Charts should support horizontal scrolling/panning to view historical data
- Weight & Waist Trend chart: dual y-axis with Weight (lbs) on left, Waist (inches) on right
- Two-finger drag to pan charts on mobile

# Data Storage
- Uses browser LocalStorage (data is device-specific, not synced)
- Primary usage is on iPhone
- Export CSV regularly for backup
